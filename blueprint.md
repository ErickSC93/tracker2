# **App Name**: Calibration Tracker

## Core Features:

- Equipment Registration: Register client equipment with details: company name, ID, model, serial number, description, reception date, technician, and observations. Includes a save button that clears the fields (except the company name) upon saving.
- Process Tracking: Track the equipment's process with the following statuses: received, processing, calibrated, and delivered.
- Equipment Search: Search for equipment using either the ID or client name to view and update its process status.
- QR Code Scanning: Scan a QR code to quickly find and update the equipment's process status. Upon successful scan, navigate to the equipment's record for updates.
- Delivery Confirmation: In the delivery tab, scan or enter the equipment ID to confirm its completion process and allow reviewing process before delivery.
- Online Status: View the status and process of the calibration equipment online in real-time. This feature would give better transparency with the clients and a better workflow.

## Style Guidelines:

- Primary color: Deep Blue (#3F51B5) to evoke trust and precision, fitting for a laboratory setting.
- Background color: Light Gray (#F0F0F0), providing a clean, neutral backdrop for easy readability and focus on data.
- Accent color: Teal (#009688) to highlight key actions and status indicators, offering a fresh and modern contrast to the primary blue.
- Body and headline font: 'Inter', sans-serif. Suitable for both headlines and body text
- Use simple, clear icons to represent each status (e.g., a gear for processing, a checkmark for calibrated) and actions (search, save, scan).
- A clean, tab-based layout to separate registration, tracking, and delivery confirmation functionalities. Use clear, consistent labels for all fields and buttons.
- Subtle animations to indicate status changes and successful actions, such as a fading in effect when saving data or a slide-in animation when transitioning between tabs.
