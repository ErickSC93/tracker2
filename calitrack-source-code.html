# Firebase Studio

This is a NextJS starter in Firebase Studio.

To get started, take a look at src/app/page.tsx.

## Setting up Admin Features

To enable user management features in the admin panel, you need to configure your Firebase Admin SDK credentials. Follow the guide here: [docs/SETUP_ADMIN_SDK.md](./docs/SETUP_ADMIN_SDK.md).
